# Ranked Decisions Ledger

This file acts as the Recall layer of the Memory Harness, tracking important decisions and their rationales prioritized by impact.

## Decision 1
- **Context:** Deciding how to implement the Recall layer.
- **Decision:** Use a Ranked Decisions Ledger (`ranked-decisions.md`) instead of generic RAG.
- **Rationale:** As per Stefania Druga's presentation, prioritizing step-by-step decisions outperforms standard RAG and prevents the agent from being led in the wrong direction by poorly retrieved context.

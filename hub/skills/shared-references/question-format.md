# Question Format Guide

## When Asking Questions

All clarifying questions MUST use multiple-choice format with A/B/C/D/E options.

## Format

```
**[Question text]**

A. [Option A description]
B. [Option B description]
C. [Option C description]
D. [Option D description — if needed]
E. Other / specify

[Answer]: _
```

## Rules

1. Provide 2-5 distinct, mutually exclusive options (unless multi-select is needed)
2. Include "Other / specify" as the last option when user may have an unlisted answer
3. User answers by filling in `[Answer]: A` (or their chosen letter)
4. If the answer is ambiguous (e.g., "B and C"), ask a follow-up to resolve
5. Never present more than 5 options per question
6. Do not use open-ended questions when options can cover the space

# Validation Spec — aidlc-infrastructure-design

## Preconditions (machine-checkable)

- [ ] `aidlc-docs/aidlc-state.md` exists and contains an active unit entry
- [ ] Active unit `aidlc-docs/construction/{unit}/INDEX.md` exists
- [ ] NFR Design stage status `done` or `skipped` for active unit
- [ ] `audit.md` tail contains `APPROVAL-STAGE: NFR_DESIGN_APPROVED [unit={unit}]` or `SKIP: NFR Design — ...` or `SKIP: NFR Requirements — ...`
- [ ] Execute-IF criteria evaluated (skip if no infrastructure changes or infrastructure already defined)

## Artefact contract

| Artefact path | Required | Validation |
|---|---|---|
| `aidlc-docs/construction/{unit}/infrastructure-design/` (directory) | yes (if executed) | Must contain: logical component to AWS infrastructure mapping (ECS/EKS services, RDS, ElastiCache, S3, CloudFront), Kubernetes/ECS task definitions, Terraform resource specifications, network topology (VPC, subnets, security groups), Kafka topics and consumer groups, Keycloak realm/client config where applicable |
| `aidlc-docs/audit.md` | yes (append) | Must contain start log entry and `APPROVAL-STAGE: INFRASTRUCTURE_DESIGN_APPROVED [unit={unit}]` on completion |

**Content validation requirement**: ASCII diagrams must be validated per `references/content-validation.md` before writing.

**Conditional artefact**:
- If new Terraform resources required: IaC code generated by `codegen-iac` subagent in `infra/` directory (blocking, must complete before gate).
- If vague-keyword scan finds `depends / maybe / not sure / unclear / TBD / mix of / somewhere between / standard / typical / usual / and/or / etc.`: create `aidlc-docs/construction/{unit}/infrastructure-design-questions.md`. All `[Answer]:` tags must be filled before approval gate.

**Skip artefact**: If skipped, `aidlc-docs/audit.md` must contain skip entry and `[x] Infrastructure Design` marked in unit's construction progress.

## Gate marker contract

- Expected pre-marker: `APPROVAL-STAGE: NFR_DESIGN_APPROVED [unit={unit}]` or skip markers for NFR Design / NFR Requirements
- Emit on completion: `APPROVAL-STAGE: INFRASTRUCTURE_DESIGN_APPROVED [unit={unit}]`
- Marker is appended to `aidlc-docs/audit.md`
- `[x] Infrastructure Design` is marked in the unit's `## Construction Progress`

## Subagent dispatch contract

- **BLOCKING subagents**: `codegen-iac` — if new Terraform resources are required (Step 3). Must complete before approval gate is presented.
- **Conditional subagents**: `adr-curator` — if a significant infrastructure decision has no existing ADR. Must complete before approval gate.

## Failure modes

| Condition | Action |
|---|---|
| Active unit not identified | Delegate to `aidlc-workflow`; return |
| Execute-IF not met (should skip) | Write skip entry; mark `[x] Infrastructure Design`; return |
| `codegen-iac` subagent fails | Surface error; do NOT present gate; wait for user intervention before retry |
| ASCII diagram validation fails | Fix diagram before writing file; do NOT write invalid content |
| Vague-keyword scan finds issues | Create questions file; wait for all answers; update artifact before gate |
| No ADR governs a significant infrastructure decision | Invoke `adr-curator`; wait for ADR draft; cite in output before gate |
| User selects "Option 1 — Request Changes" at gate | Update artifact; re-present the same gate (do NOT advance) |
